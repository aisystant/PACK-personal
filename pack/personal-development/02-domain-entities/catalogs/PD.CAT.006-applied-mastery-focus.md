# PD.CAT.006 — Осваиваемые прикладные мастерства

> Список прикладных мастерств (D.194), которые пилот сейчас держит в фокусе развития. Не выводится из поведенческих данных (сна, устойчивости фокуса и т.п.) - только явное имя от пилота; данные могут дополнять уже названную запись как контекст, но не создают запись сами по себе.

## Структура записи

| Поле | Описание |
|------|----------|
| Название | Имя прикладного мастерства |
| Вид | профессиональное / бытовое / ухода за собой (PD.FORM.019 §6) |
| Метод | конкретный прикладной метод, которым осваивается (если назван) |
| Статус | в фокусе / фоновое / приостановлено |

## Текущие записи

| Название | Вид | Метод | Статус |
|----------|-----|-------|--------|
| Плавание | ухода за собой | кроль (упомянут как пример) | кандидат, не подтверждено |
| Фортепиано | бытовое | не назван | **в фокусе** — подтверждено пилотом 07.08 («сейчас фортепиано», разбор заметок, РП-513); репертуар — 2 пьесы целиком + сложная пьеса в работе, занимается ежедневно (~3-4ч/нед) — по независимой 4-уровневой шкале (WP-513, не по колонкам этого каталога) это уровень 2, подтверждено и по репертуару, и по регулярности |
