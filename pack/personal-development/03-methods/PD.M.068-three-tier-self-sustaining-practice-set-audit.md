# PD.M.068 — Трёхуровневая проверка минимального самоподдерживающегося набора практик

## Проблема

Интуитивно собранный bootstrap-список практик/методов «стиля жизни» не даёт проверяемого ответа на вопрос, какие из них действительно необходимы для самоподдерживающегося контура, а какие держатся только потому, что от них зависит что-то другое — или вообще не имеют собственного механизма пересмотра.

## Метод (3 уровня)

1. **Уровень 1 — самоподдерживающееся ядро.** У каждого метода этого уровня СОБСТВЕННЫЙ decision-bearing триггер пересмотра (не календарный ритуал «раз в месяц посмотреть») — конкретное наблюдаемое событие, по которому метод пересматривается.
2. **Уровень 2 — несущий слой.** Даёт отдельный содержательный вклад, но триггер пересмотра для него приходит ОТ метода уровня 1, не свой собственный.
3. **Уровень 3 — базовая предпосылка.** Засчитывается в самоподдерживающийся контур только при явном триггере; без него — фоновая гигиена без обратной связи, не часть контура.

Для каждого метода каталога явно проверяется: (а) есть ли у него собственный decision-bearing триггер, или триггер наследуется от метода уровня 1; (б) входит ли метод в контур непрерывно или только по пороговому условию.

## Результат

Интуитивный список практик заменяется проверяемой структурой: минимальный самоподдерживающийся набор — это набор, где каждый метод либо сам несёт decision-bearing триггер (ядро), либо явно наследует его от ядра (несущий слой), либо явно помечен как предпосылка без самостоятельного веса в контуре (уровень 3).

## Применимость

Любая задача выбора минимального набора практик/правил для самоподдерживающейся системы — не только стиль жизни: оценка набора эксплуатационных правил, набора ежедневных ритуалов агента, минимального набора guard'ов конвейера.
