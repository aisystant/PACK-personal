# PD.METHOD.062 — Трёхуровневая структура минимального набора методов по типу триггера пересмотра

## Суть метода

При проверке набора методов/практик на минимальность каждый элемент классифицируется по ТИПУ его триггера пересмотра, не по интуитивному чувству «нужности»: **Уровень 1** — методы с собственным decision-bearing триггером, не календарным ритуалом (обнаруженная ошибка, sunk-cost сигнал, нарушение границы agency); **Уровень 2** — методы с уникальным вкладом (вход/выход/stop-condition), но триггер пересмотра которых приходит ОТ уровня 1, не свой собственный; **Уровень 3** — базовая предпосылка, на которой держатся оба уровня. Таксономия типов триггеров используется как чек-лист покрытия: для каждого класса жизненных ситуаций проверяется, какой уровень на него отвечает и отвечает ли вообще.

## Обоснование

Интуитивный «стартовый набор» (просто перечисление нескольких ID без критерия) не может быть проверен на минимальность или самоподдержание — непонятно, какой элемент необходим и какой пробел в покрытии остался незамеченным. Классификация по типу триггера даёт проверяемый критерий: элемент без собственного и без наследуемого триггера пересмотра — не часть минимального самоподдерживающегося набора; а применение таксономии как чек-листа вскрывает пробелы, которые перечисление не видит.

## Применение

Проверка любого каталога методов/практик на минимальность и самоподдержание — не только личных методов, любой набор процедур, который должен работать без постоянного волевого контроля.

## Прецедент

WP-600 Ф2: каталог из 34 методов стиля жизни/работы (`docs/catalog-methods-style-ai-era.md`) имел интуитивно выбранный стартовый набор. Пир-сессия (паттерны FPF/DPF HCD.5 «Select a Coherent Method Set» и HCD.15 «Make triggers decision-bearing») заменила его трёхуровневой структурой и применила таксономию как тест покрытия — вскрыт реальный, явно зафиксированный как открытый пробел: ни один из 34 методов не отвечает на триггер «потеря критической внешней опоры» (специалист/источник/доступ стали недоступны не по вине пользователя и не из-за устаревшего правила).
